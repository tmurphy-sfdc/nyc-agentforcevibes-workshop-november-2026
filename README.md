# NYC Agentforce Vibes Workshop

Workshop site for the Agentforce Vibes workshop (multi-agency NYC-area audience).

Structure modeled on the MTA ServicePulse 360 workshop site (SAY/DO/transition
lab format, countdown timer, sidebar checklists), adapted for a shorter
single-day / half-day format.

## Structure
- `workshop-site/` — the published site (GitHub Pages serves this folder)
  - `index.html` — main site shell
  - `assets/` — images, fonts, styles, scripts
  - `labs/` — per-lab materials
