Workshop Tools & Objectives Walkthrough

11:00 – 11:10 AM · ~10 min

Launch and Get Familiar with Agentforce Vibes

A fast, guided walkthrough before hands-on time begins: what Agentforce Vibes is, how to launch it, and the IDE areas you'll use for the rest of the session.

What you're building toward

Agentforce Vibes is Salesforce's enterprise-grade vibe coding environment, a context-aware, AI-powered IDE that turns natural language into working Salesforce applications. Built on the Salesforce Platform and Trust Layer, Vibes accelerates every stage of the development lifecycle: planning, building, testing, deploying, and iterating.

Unlike basic AI code assistants that generate snippets, Agentforce Vibes is designed specifically for secure, governed enterprise development. It understands your org's metadata, adheres to your patterns and Rules, and works with Salesforce tools such as Sandboxes, Code Analyzer, DevOps Center, and the Salesforce DX MCP server.

Why this mattersWhen you interact with Agentforce Vibes, you're collaborating with an autonomous coding partner that can analyze your project, create detailed plans, scaffold metadata, generate Apex and Lightning Web Components, refactor existing code, resolve bugs, and deploy your app, all through natural language.

Step 1: Launch Agentforce Vibes

1.Open the Setup Menu and click Agentforce Vibes.
2.Accept the Terms and Conditions.
TipIt will take a few minutes for Agentforce Vibes to fully initialize. A Salesforce DX project will be automatically created for you and your org will be authorized by default.
TipYou may see a number of notifications in the bottom right of the IDE. This is where IDE or extension notifications are published. You can close any that appear on launch.
3.The Agentforce Sidebar should be open by default. If it isn't, select the Agentforce Vibes Icon in the sidebar to open it.
4.Select I agree to the terms and click Enable and Start Building.

Step 2: Get Familiar with the Agentforce Vibes IDE

1.Open the command palette (CMD+SHIFT+P on Mac or CTRL+SHIFT+P on PC). Use it to access Agentforce Vibes commands, SFDX commands, Lightning Preview, and project tools and utilities.
(Optional) Change your IDE theme by opening the command palette and searching for Color Theme.
2.Open the Explorer Sidebar to view your project files. Generated Apex classes, Lightning Web Components, and metadata will appear here.
3.Open the Org Browser Sidebar (cloud icon in the Activity Bar, or search Org Browser: Focus on Metadata View in the Command Palette). Use it to browse metadata in your org, expand objects, fields, Apex classes, and LWCs, and download metadata directly into your SFDX project.
TipDownloaded metadata gives Agentforce Vibes the context it needs for accurate planning and code generation.
4.Open the Extensions Sidebar to confirm the Salesforce Extension Pack is installed. This includes tools for SFDX commands, Org Browser, Lightning Preview, and MCP support.
5.Open the Integrated Terminal (CTRL+` on both Mac and Windows) to view output from SFDX commands, run optional CLI commands, and inspect logs or deployment messages.
6.Check the Status Bar at the bottom of the IDE. It shows your authorized org, active project, Lightning Preview activity, and MCP server status.
Watch forIf something appears to be "stuck," the Status Bar is usually where you'll see what the IDE is waiting on.

Summary

By the end of this walkthrough, you'll have launched Agentforce Vibes and activated it in your org, walked through the initial setup flow, enabled the agent, and confirmed your development environment and sidebar are initialized correctly. With Vibes running inside your IDE, you're ready to move into hands-on build time.
